# ANT TRACKER v0.1

USB 웹캠으로 파란색 젤 사육장을 촬영하고, 브라우저에서 검정색·갈색 개미의 위치와 이동 경로를 실시간으로 기록하는 프로토타입입니다. 영상 업로드 프로그램이 아니며, 별도 Python 서버나 AI 모델을 사용하지 않습니다.

웹캠 프레임, 검출 결과, 좌표 기록은 모두 사용자의 브라우저 메모리 안에서 처리됩니다. 웹캠 영상은 외부 서버로 업로드되지 않습니다. 단, OpenCV.js 실행 파일과 웹 폰트는 처음 실행할 때 각각 공식 OpenCV CDN과 Google Fonts에서 내려받습니다.

## 준비물

- USB 웹캠 또는 PC 내장 카메라
- 네 모서리에 붙일 노란색 원형 스티커 4개
- Node.js 20 이상과 npm
- 최신 Chrome 또는 Edge 권장

카메라 접근은 보안 정책상 `localhost` 또는 HTTPS에서만 허용됩니다. 아래 개발 서버로 실행하면 `localhost`를 사용하므로 정상적으로 권한을 요청할 수 있습니다.

## 설치와 실행

터미널에서 이 폴더로 이동한 후 다음 명령을 순서대로 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 주소(일반적으로 `http://localhost:5173`)를 Chrome 또는 Edge에서 엽니다.

이미 개발 서버가 실행 중이었다면 수정된 코드를 확실히 적용하기 위해 터미널에서 `Ctrl+C`로 종료한 뒤 `npm run dev`를 다시 실행하고, 브라우저에서 `Ctrl+F5`로 강력 새로고침하세요. `5173` 포트가 사용 중이면 Vite가 `5174`처럼 다른 주소를 표시하므로 반드시 터미널에 새로 출력된 주소를 엽니다.

배포용 파일이 정상적으로 만들어지는지 확인하려면 다음을 실행합니다.

```bash
npm run build
npm run lint
```

빌드 결과는 `dist/` 폴더에 생성됩니다. 빌드 결과를 로컬에서 확인하려면 `npm run preview`를 실행합니다.

## 처음 사용하는 순서

### 1. 사육장과 웹캠 설치

투명 사육장 네 모서리에 노란색 원형 스티커를 붙입니다. 스티커 중심이 실제 사육장 내부 영역의 네 꼭짓점을 나타내도록 배치하는 것이 좋습니다.

정확한 거리 측정을 위해 웹캠을 사육장 정면에 최대한 수직으로 설치하세요.

v0.1은 Perspective Transform이나 Homography를 사용하지 않습니다. 카메라가 사육장 면에 비스듬하면 픽셀과 실제 거리의 비율이 위치마다 달라져 cm 측정 오차가 커집니다. 카메라가 흔들리지 않게 고정하고, 반사광이 적도록 조명을 조절하세요.

### 2. 카메라 선택과 권한 허용

1. 화면 오른쪽의 **Camera** 목록에서 USB 웹캠을 선택합니다.
2. 이름이 보이지 않으면 **카메라 시작**을 한 번 누르고 브라우저의 카메라 권한을 **허용**합니다.
3. 권한 허용 뒤 목록을 새로고침하면 `USB Camera` 같은 실제 장치명이 표시됩니다.
4. 원하는 장치를 선택하고 **카메라 시작**을 누릅니다.

기본적으로 1280×720, 30 FPS를 우선 요청합니다. 카메라가 지원하지 않으면 브라우저가 가능한 해상도를 선택하며, 실제 해상도와 표시 FPS는 Camera 패널에 나타납니다. 카메라를 바꾸면 기존 스트림을 종료한 뒤 새 스트림을 시작하고 기존 ROI는 초기화됩니다.

휴대폰을 Windows 가상 카메라로 사용하는 경우에는 휴대폰 카메라 연결을 먼저 활성화한 뒤 웹페이지를 새로고침하세요. 앱은 재연결로 사라진 이전 장치 ID를 자동으로 폐기하고, 1280×720 요청이 실패하면 장치 기본 설정과 640×480 설정으로 순차 재시도합니다. Windows 카메라 앱이나 화상회의 프로그램이 카메라를 사용 중이면 먼저 종료하세요.

권한을 실수로 차단했다면 주소창 왼쪽의 사이트 설정 아이콘에서 카메라 권한을 허용한 후 페이지를 새로고침하세요.

OpenCV가 `failed`로 표시되면 오류 알림의 **OpenCV 다시 시도**를 누릅니다. OpenCV.js는 공식 `docs.opencv.org/4.9.0` CDN에서 내려받으므로 최초 실행 시 인터넷 연결이 필요합니다. OpenCV 로딩과 영상 분석은 별도 Web Worker에서 실행되므로 초기 다운로드·컴파일 중에도 페이지 UI는 응답해야 합니다.

### 3. 사육장 분석 영역 지정

1. **영역 설정**을 누릅니다.
2. 영상에서 노란 스티커 중심을 다음 순서로 클릭합니다.
   1. `A`: 좌측 상단
   2. `B`: 우측 상단
   3. `C`: 우측 하단
   4. `D`: 좌측 하단
3. 네 점이 선으로 연결되면 설정이 완료된 것입니다.

실수했으면 **마지막 점 취소**, **초기화**, **다시 설정**을 사용합니다. 검출기는 이 사각 polygon 내부의 픽셀만 처리하며 ROI 바깥의 물체는 완전히 무시합니다.

### 4. 실제 사육장 크기 입력

자로 잰 사육장 분석 영역의 가로와 세로를 cm 단위로 입력합니다. 예를 들어 가로 20 cm, 세로 15 cm라면 각각 `20`, `15`를 입력합니다.

앱은 `A-B`와 `D-C` 길이의 평균을 가로 픽셀 길이로, `A-D`와 `B-C` 길이의 평균을 세로 픽셀 길이로 사용합니다. 이 값으로 x/y 축의 대략적인 px → cm 비율을 계산합니다. 원근 보정을 하지 않으므로 결과는 근사값입니다.

### 5. 개미 검출값 조정

추적을 시작하기 전에도 파란색 사각형으로 검출 후보를 확인할 수 있습니다. **검출 마스크**를 켜면 흰색으로 분류된 후보 픽셀을 별도 화면에서 볼 수 있습니다.

- **밝기 Threshold**: HSV의 밝기(Value)가 이 값 이하인 픽셀을 어두운 개미 후보로 봅니다. 개미가 안 보이면 값을 조금 올리고, 젤이나 그림자가 너무 많이 잡히면 내립니다.
- **최소 면적**: 먼지나 작은 영상 노이즈가 잡히면 올립니다.
- **최대 면적**: 큰 그림자나 반사 영역이 잡히면 내립니다. 실제 개미가 제외되지 않도록 여유를 둡니다.
- **Hue/채도 범위**: 기본값은 모든 색상을 허용합니다. 조명 환경에서 특정 색의 오검출이 많을 때만 조정합니다.
- **Blur**: 작은 영상 노이즈를 부드럽게 만듭니다. 너무 높으면 작은 개미가 사라질 수 있습니다.
- **Morphology**: 작은 점을 제거하고 끊어진 개미 영역을 잇습니다. 너무 높으면 가까운 개미가 하나로 합쳐질 수 있습니다.
- **최대 종횡비**: 지나치게 길고 가는 반사나 테두리를 제외합니다.
- **분석 FPS / 분석 너비**: 기본 분석은 640px, 12 FPS입니다. 느리면 값을 낮추고, 작은 개미를 놓치면 분석 너비를 높입니다.

조명, 웹캠 노출, 개미 크기에 따라 적절한 값이 달라집니다. 하나의 고정 Threshold가 모든 환경에서 맞지는 않습니다.

### 6. 추적과 저장

1. 상태 표시가 `OpenCV ready`, `Camera ready`, `Tracking ready`인지 확인합니다.
2. **추적 시작**을 누릅니다. 이 시점이 CSV timestamp `0.000`초입니다.
3. 필요하면 **일시정지**와 **추적 재개**를 사용합니다. 일시정지 시간은 추적 시간에서 제외됩니다.
4. 완료되면 **추적 종료**를 누릅니다.
5. **CSV 다운로드**를 누릅니다.

파일 이름은 `ant-tracking-YYYY-MM-DD.csv`이고 다음 열을 포함합니다.

```text
timestamp,antId,xPixel,yPixel,xCm,yCm,speedCmPerSec,isMoving
```

`isMoving`은 직전 검출 위치와의 cm 거리가 **정지 판정 거리** 이상인지 나타냅니다. 그보다 작은 변화는 영상 노이즈로 보고 총 이동거리에 더하지 않습니다.

## 화면 옵션

- **ID 표시**: 현재 추적 ID(`Ant 1`, `Ant 2` 등)를 표시합니다.
- **현재 위치**: 개체 centroid에 점을 표시합니다.
- **이동 경로**: ID별 최근 경로를 선으로 표시합니다.
- **분석 영역**: A-B-C-D ROI 경계를 표시합니다.
- **검출 마스크**: OpenCV.js binary mask를 별도로 표시합니다.

화면 경로는 기본적으로 개체당 최근 300개 점만 보관해 렌더링 비용을 제한합니다. CSV용 전체 좌표 기록은 세션이 끝날 때까지 별도로 유지됩니다.

## 작동 방식

1. `getUserMedia()`와 `enumerateDevices()`로 카메라를 선택합니다.
2. 원본 영상은 Canvas에 그대로 표시합니다.
3. 사용자가 지정한 네 점으로 polygon ROI mask를 만듭니다.
4. 분석용 프레임만 기본 640px 너비로 축소합니다.
5. OpenCV.js에서 RGB → HSV 변환, 밝기/색상 범위 threshold, morphology open/close를 수행합니다.
6. ROI 내부 contour만 찾고 면적·크기·종횡비로 노이즈를 제외합니다.
7. contour centroid와 기존 위치의 최근접 거리를 비교해 ID를 연결합니다.
8. 좌표, 이동거리, 평균속도와 움직임 상태를 누적하고 CSV로 저장합니다.

## 현재 버전의 한계

- 개미가 서로 완전히 겹쳤다가 갈라지면 ID가 바뀔 수 있습니다.
- 매우 비슷한 거리에서 빠르게 교차하는 개미는 nearest-neighbor 방식의 한계로 ID가 교환될 수 있습니다.
- 정지한 먼지나 짙은 그림자가 Threshold와 크기 조건에 맞으면 개미로 검출될 수 있습니다.
- 카메라 자동 노출 변화, 반사광, 젤 내부의 기포가 검출에 영향을 줄 수 있습니다.
- 원근 보정을 하지 않으므로 카메라가 기울어질수록 실제 거리 오차가 커집니다.
- 데이터는 서버 DB에 저장되지 않습니다. 페이지를 닫기 전에 CSV를 내려받아야 합니다.
- 히트맵은 v0.1 UI에 포함하지 않았지만 전체 좌표 기록 구조를 그대로 사용해 추가할 수 있습니다.

## 다음 버전에서 개선할 기능

가장 먼저 **배경 학습을 이용한 조명·먼지 오검출 감소와 검출 설정 preset 저장**을 권장합니다. 이후 필요에 따라 전체/개별 히트맵, Kalman Filter, Hungarian Algorithm, ByteTrack 계열 matching, appearance feature, 딥러닝 기반 re-identification을 단계적으로 추가할 수 있습니다. v0.1 tracker는 검출기와 분리되어 있어 교체하기 쉽습니다.

Perspective Transform과 Homography는 촬영 환경에서 실제 필요성이 확인된 뒤 별도 버전에서 추가하는 것이 좋습니다.
